# Fadli Tobiansyah — Developer Portfolio

Website portfolio statis untuk GitHub Pages.

## Cara publikasi
1. Upload `index.html`, `style.css`, `script.js`, dan folder `assets` ke repository `Cv-portfolio`.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
5. Tunggu proses deploy selesai. Website akan tersedia di:
   https://ftobiansyah123.github.io/Cv-portfolio/

## Sebelum dipublikasikan
- Ganti `emailkamu@example.com` di `index.html` dengan email aktif.
- Tambahkan foto profil dan CV PDF bila sudah siap.
- Periksa kembali isi pengalaman, skill, dan proyek agar sesuai fakta serta portofolio yang dapat ditunjukkan.

Dibuat dengan HTML, CSS, dan JavaScript tanpa framework.
